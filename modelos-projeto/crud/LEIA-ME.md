# Modelo CRUD

1. Instale: copie a pasta `crud` para dentro do seu projeto e abra `index.html` no navegador.
2. Configure as variáveis em `modelo.json` (`nome`, `titulo`, `campos` e `cor`).
3. O formulário envia os dados para a API em `/api/dados` (GET, POST, PUT e DELETE).
4. Se a chamada falhar, os dados ficam guardados no `localStorage` do navegador.
