# Modelo CRUD
Tela de cadastro: listar, buscar, criar, editar e apagar registros.
Variáveis: nome, titulo, campos (separados por vírgula, todos obrigatórios) e cor.
Os dados vão para `/api/dados` do projeto; sem servidor, ficam no navegador e a tela avisa.
Sem instalar nada: só HTML, CSS e JavaScript.
