# Modelo CRUD

1. Instale o modelo: copie a pasta `crud` para dentro do seu projeto.
2. Abra `index.html` no navegador para ver o CRUD funcionando.
3. Configure as variáveis de ambiente (URL da API e chave) em `modelo.json`.
4. A API é chamada em `/api/dados` (GET, POST, PUT, DELETE); os dados são armazenados em `localStorage` caso a chamada falhe.
