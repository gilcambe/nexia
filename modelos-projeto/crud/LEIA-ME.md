# Modelo CRUD

1. Instale: copie a pasta `crud` para dentro do seu projeto.
2. Abra `index.html` no navegador.
3. Configure as variáveis em `modelo.json` (nome, campos do formulário e endereço da API).
4. A API é chamada em `/api/dados` (GET, POST, PUT, DELETE).
5. Se a chamada falhar, os dados são armazenados no `localStorage`.
