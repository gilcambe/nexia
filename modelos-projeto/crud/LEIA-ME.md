# Modelo CRUD

1. Copie a pasta `crud` para dentro do seu projeto e abra `index.html` no navegador.
2. Em `modelo.json`, ajuste o nome e os campos do formulário.
3. A API é chamada em `/api/dados` (GET, POST, PUT, DELETE); se falhar, os dados ficam no `localStorage`.
4. A lógica do formulário e das chamadas fica em `crud.js`, já incluído na pasta.
