# Modelo site PHP para Hostinger (hospedagem compartilhada)
Páginas: index.php e contato.php, com topo.php e rodape.php em comum. Sem banco de dados.
O contato só confere os campos e abre o WhatsApp com a mensagem pronta (nada é gravado).
Variáveis: nome, titulo, whatsapp (só números, com 55 e DDD) e cor. Precisa de PHP 7.4 ou superior.
Enviar: suba todos os arquivos para a pasta public_html (o .htaccess bloqueia os arquivos internos).
