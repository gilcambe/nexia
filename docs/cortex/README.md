# Documentação do Cortex

O Cortex é a inteligência artificial do NEXIA que realiza tarefas de desenvolvimento e manutenção de software de forma autônoma. Com base em prompts claros, o Cortex analisa o código, identifica problemas, implementa soluções e documenta suas ações, permitindo que o dono do sistema delegue tarefas técnicas de forma simples e eficiente.
