# Lições do Cortex

Este arquivo armazena lições aprendidas pelo Cortex a partir de falhas repetidas.

## Formato
Cada lição contém:
- Data: quando a lição foi registrada
- O que foi tentado: descrição da ação que falhou
- O que deu errado: descrição do erro que se repetiu
- Regra para não repetir: como evitar o erro no futuro
