# Marca Kernex

Fonte única da marca. Todo produto puxa o logo, as cores e a vinheta daqui.

| Arquivo | Uso |
|---|---|
| `logo-fundo-escuro.svg` / `.png` | Logo completo (símbolo + KERNEX + frase) sobre fundo escuro |
| `logo-fundo-claro.svg` / `.png` | Logo completo sobre fundo claro (texto azul-marinho) |
| `simbolo.svg` | Só o símbolo (hexágono), sem texto |
| `abertura-app-2s.mp4` | Vinheta de 2 s ao abrir os apps |
| `abertura-site-2s.mp4` | Vinheta de 2 s dos sites |
| `cores.json` | Cores, fonte e frase |

Regras:
- O ícone de cada app, site ou cliente é o do **próprio produto**. A Kernex aparece só na vinheta de 2 s e no selo "Feito com Kernex".
- A vinheta aparece uma vez por sessão, sem som, e um toque pula.
- Nomes internos (`nexia-*`, coleções `nexia_*`, segredos) **não mudam**.
