Perguntas Frequentes

Onde o arquivo design.json é salvo?

Ele é gravado automaticamente em clientes/<slug>/design.json.

O diretório é criado caso não exista?

Sim, o script garante que a árvore de diretórios seja criada antes da escrita.

Como os erros de escrita são tratados?

Qualquer falha de I/O é capturada e reportada sem quebrar o processo principal.

Qual o limite de linhas alteradas?

A tarefa restringe as alterações a até 400 linhas no arquivo scripts/clonar-site.js.

Pronto para integrar?

Adicione o script ao seu projeto e automatize sua pipeline.
